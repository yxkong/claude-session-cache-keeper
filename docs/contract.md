# CacheKeeper 0.4.0

## 范围与验收

独立桌面应用包含连接插件。用户下载对应系统的应用包，在应用中安装连接插件后，选择会话并单独开启保活。支持 macOS、Windows、Linux 的同一界面与本地文件协议；API 请求继续由 Claude Code 原会话发送，应用不持有 API Key。

保留默认随机 260～280 秒、默认建议连续空闲尝试 6 次、可选最小缓存 token 门槛。间隔允许 30～280 秒的整数，最短不超过最长；尝试次数允许正安全整数，不设业务上限；token 门槛为 0～1000 万的整数。达到用户配置的次数后结束本轮。每条新连接默认关闭；保存配置不自动开启；正常请求重置预算，保活不重置。缓存未命中、失败、过期或次数耗尽时停止本轮。不能保证自定义 API 源的缓存命中或固定金额费用。

## 迁移设计

0.4.0 用 Tauri 2、Rust 和系统 WebView 替换 Electron。保留现有 HTML/CSS/JavaScript 界面，不引入新前端框架；会话读写、标题解析、CLI 安装、GitHub 下载与更新均由 Rust 负责。分发包不包含 Chromium、Node、Bun、node_modules 或测试辅助程序。

以 [CC Switch 4.0.23](https://github.com/farion1231/cc-switch/tree/v4.0.23/src-tauri) 的架构和发布流程为参考。它的 Mac 通用 DMG 为约 36 MiB。原 Electron 版本 Mac 通用包约 217 MiB、安装后约 500 MiB；体积是本次替换的直接原因。安装包预算为 Mac 40 MiB、Windows 30 MiB、Linux DEB 30 MiB、Linux AppImage 120 MiB；AppImage 会携带更多系统依赖，单独衡量。

`plugin/hooks/policy.ts` 仍是保活参数和状态机的唯一 owner。构建器导出限制、默认值和边界样例；Rust 编译嵌入生成结果并用同一批样例核验。连接插件 0.2.2 增加参数元数据导出，执行行为和桥接协议 1 保持兼容。

## 状态与安全边界

执行器使用各系统用户主目录下的 `.cache-keeper/`，可由 `CACHE_KEEPER_DATA_DIR` 覆盖。macOS 可显示旧版 `ClaudeCacheKeeper` 数据，但旧连接只允许停止。安装新版插件前停用旧插件与旧开关，避免两份执行器同时花费。失败恢复原 marketplace；只有确认新版已停用才恢复旧插件，保活开关保持停止。

应用只显示已发布连接，按本机转录元数据显示真实标题，不通过模型猜标题。未完成的状态写入保留最近一份有效快照。控制请求只接受会话 ID 和参数，由 Rust 核对快照、在线状态、执行器能力及参数后原子写入。前端不接受任意文件路径，没有通用文件、shell、网络或更新器权限。

关闭窗口后留在托盘；正常退出先停止已知连接，停止失败时保留应用并显示原因。强制退出仍可能保留已开启轮次的剩余尝试。插件更新不自动重载或重启 Claude；以目标会话报告的版本确认加载。正在工作、续热或保活开启时不能安装插件或原生应用更新。

## 实现与验收顺序

1. Rust 会话桥接：合成会话读取、单条保存、默认关闭、停止、旧连接、真实标题及边界校验。
2. 保留界面：通过原生 Rust 测试进程运行组件测试，核验草稿、停止按钮、状态点及更新入口。
3. 安装和更新：CLI 参数边界、超时、禁止降级、失败恢复、来源白名单、体积与 SHA-256、签名、取消下载。
4. 原生交付：本机 Mac 实包及隔离 WebView 启动；三端 CI 各自在目标系统构建，产出完整清单后才允许发布。

构建、启动、视觉验收和真实 API 使用分别记录；没有实际证据的项目标记 NOT_RUN。验证不修改真实会话开关、不安装真实插件、不发送付费请求。
