# CacheKeeper by yxkong

个人品牌署名为 `yxkong`，中文关联「鱼翔空说 AI」。产品视觉沿用清爽、理性、真实可用的表达，避免机器人、霓虹宇宙和第三方工具标志拼贴。

- 冷白：`#F3FAFA`；深墨蓝：`#14213D`；行动青绿：`#00C288`。
- 图形：抽象鱼形与缓存续热循环结合，绿点表示运行状态。
- 名称：CacheKeeper；副署名：by yxkong。
- 主图：`assets/brand/logo-master.png`，由 imagegen 基于上述品牌约束生成。
- `scripts/icons.mjs` 仅做尺寸和容器格式转换，生成 PNG、ICO、ICNS 及插件图标。
- Logo 为 24px，名称与署名位于左侧会话栏顶部；窗口顶部仅保留 38px 工具栏。会话列表采用约 36px 高的单行标题与状态点，项目和 ID 放入悬停提示及详情；会话标题和保活开关优先于品牌展示。
- Mac 菜单栏另用 `assets/brand/tray-master.png`：透明单色鱼形循环图标，18pt 与 2x 资源，由系统按深浅色模式着色。完整彩色图标用于 Dock 与应用列表。

这是独立项目标识，与 Claude/Anthropic 官方品牌无关联。
